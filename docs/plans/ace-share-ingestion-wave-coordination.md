## Source Inventory and Bounded Read Contract

- Root abstraction: `ACE_SHARE_ROOT`. No raw absolute source path should be copied into this repo artifact.
- Named manifest sources: `INDEX.md`, `assets.json`, `docs/master-index.jsonl`, `_cad-index/index-summary.json`, `_cad-index/cad-readability-index.tsv`, and `.ace-knowledge/index.db`.
- Seed/sort rule: stable sort by `source_id`, then seeded sample `ace-epic-50-2026-06-29`.
- Row caps: 200 manifest rows per bucket during planning or validation.
- Maximum files touched: 25 per validation proof.
- Maximum bytes touched: 1048576 per validation proof unless a later approved issue cites a bounded precomputed sidecar.
- Denied traversal patterns: recursive share walk; full-manifest materialization; full-file hashing/counting of large manifests; unrestricted `jq`; `os.walk`; `ls -R`; `find`; `du`; `rg`; `fd`; raw manifest reads via `cat` or recursive `grep`.
- Allowed proof command examples must be bounded, must use share-relative paths, and must record row caps, byte caps, and sampled manifest identity.

## Epic Gates

- Branch publication rule: dedicated planning branch or explicit stacked-branch note is required before publishing any ACE wave artifact.
- Public artifact safety gate: path-tokenization, opaque `public_source_token` use, raw source id/hash denial, generic private-like identifier checks, personal identifier checks, and proprietary snippet checks are required before docs nav, mkdocs, llm-wiki, GitHub comments, or external publication exposure; maintained private/client/project deny-list certification is the #63 gate.

Cross-wave control/gate issues use `success_metric_applicability=not_applicable_control_plane` with zero numerator/denominator/threshold and an explicit validation command. Hard exclusions are reported separately as `% excluded`.
