The test (line 579) uses author-chosen fixtures, so an adversarial pattern can pass the spec while the parser mis-handles it. Consider a minimal Python parser (already a Python-heavy plan) instead of bespoke bash YAML.

For a security-critical classifier, "described precisely" is not the same as "demonstrated buildable."
