A generic `test_raw_manifest_read_class_is_denied` is insufficient; #67 needs per-source denial coverage or an explicit #67-only extension for `INDEX.md`.

The contract field at plan line 181 lists classes like traversal and raw manifest read, and line 277 says command verbs will be neutral enum values, but no section defines the concrete syntax/token set that maps to each class. The TDD rows at lines 429-433 test one class at a time, not every inherited parent pattern in `scripts/validate_ace_epic_wave_coordination.py:146-158` or every allowed manifest key. This leaves the classifier free to pass tests with a narrow representative per class while missing real denied commands.
